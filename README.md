# 外国人名音译查询

支持 **英国 / 法国 / 西班牙 / 葡萄牙 / 德国 / 俄罗斯 / 意大利** 等 **22 种语言**的外国人名音译查询。

- 内置 **67 万条**词典译名（`人名翻译.xlsx`）
- 按所选籍贯语种自动匹配译音表
- 主译名来自词典，同时展示译音表对照结果

## 本地运行

```bash
pip install openpyxl
python app.py
```

打开浏览器访问 http://localhost:8000

## 文件说明

| 文件 | 用途 |
|------|------|
| `app.py` | 后端 HTTP 服务（内置 HTML 前端） |
| `translit.py` | 译音表转写引擎 |
| `*_table.py` | 各语种译音表（辅音 + 韵母） |
| `人名翻译.xlsx` | 词典数据（67 万条译名） |
| `index.html` | 前端页面 |
